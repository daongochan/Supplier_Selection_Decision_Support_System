# Enterprise Design System Specification — Supplier Selection DSS

**Version:** 1.5.0  
**Status:** Active Canonical Specification  
**Scope:** Design tokens, layout architecture, core components, typography, visual media assets, and zero-waterfall build pipeline.

---

## 1. Overview & Architecture

Supplier Selection DSS employs a modern, accessible, zero-waterfall CSS architecture designed for enterprise decision workflows. The visual language balances editorial clarity (using **Source Serif 4** for numerical KPIs, headers, and scores) with clean functional utility (using a modern sans-serif stack for dense tabular data and forms).

### Asset Pipeline Architecture

```
wwwroot/css/
├── tokens.css                  <-- Canonical design tokens (colors, radii, shadows, fonts)
├── base/
│   ├── typography.css          <-- Font faces, headings, text utilities
│   ├── layout.css              <-- Shell, sidebar, main canvas, breadcrumbs
│   ├── responsive.css          <-- Breakpoints (1200px, 992px, 768px, 576px)
│   └── utilities.css           <-- Global reset, alignment, and helper utilities
├── components/
│   ├── buttons.css             <-- Primary, outline, icon, and action buttons
│   ├── cards.css               <-- KPI cards, container panels, elevation
│   ├── status.css              <-- Workflow badges and status indicators
│   ├── forms.css               <-- Inputs, selects, validation feedback
│   ├── tables.css              <-- Dense data grids, matrix tables, zebra striping
│   ├── pagination.css         <-- Page navigation controls
│   ├── shared.css              <-- Modals, loaders, tooltips, dialogs
│   └── background.css          <-- Ambient canvas textures and backdrop filters
└── site.css                    <-- AUTO-GENERATED deterministic bundle (served to browser)
```

**Bundling & Determinism:**
- The served bundle `wwwroot/css/site.css` is generated by `tools/assets/bundle_css.py`.
- Running the bundler produces byte-identical output with matching SHA-256 checksums across runs.
- Page-specific stylesheets (`wwwroot/css/pages/*.css`) are loaded on-demand via `@section Styles` to keep the base payload minimal.

### Typography

- **Headings & Quantitative Metrics:** `Source Serif 4`, serif (`--font-serif`).
  Provides distinct editorial dignity for decision scores, consistency ratios, and dashboard KPIs.
- **Body & Data Tables:** System Sans-Serif (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`).
  Ensures maximum legibility in dense matrix comparisons and numerical entry tables.
- **Monospace:** `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` (`--font-mono`).
  Used for batch codes, rowversion hashes, and audit trace IDs.

### Elevation & Shadows

- `--shadow-sm`: `0 1px 2px 0 rgba(0, 0, 0, 0.05)`
- `--shadow-card`: `0 1px 3px 0 rgba(0, 0, 0, 0.08), 0 1px 2px -1px rgba(0, 0, 0, 0.05)`
- `--shadow-elevated`: `0 10px 25px -5px rgba(0, 0, 0, 0.10), 0 8px 10px -6px rgba(0, 0, 0, 0.08)`
- `--shadow-modal`: `0 25px 50px -12px rgba(15, 23, 42, 0.25)`

## 3. Visual Media Assets & Fallback Matrix

All photographic and illustrative assets are stored under `wwwroot/images/` and employ responsive `<picture>` tags with modern WebP sources and universal PNG/JPG fallbacks:

| Asset | Formats | Responsibility & Usage | Fallback Protocol |
|---|---|---|---|
| `login-left.webp` / `login-left.jpg` | WebP (24 KB) + JPG (64 KB) | Editorial visual panel on `/Account/Login` split-screen card | `<picture><source srcset="...webp" type="image/webp"><img src="...jpg"></picture>` |
| `sidebar-bg.webp` / `sidebar-bg.jpg` | WebP (18 KB) + JPG (45 KB) | Subtle ambient bottom-anchored texture on `.app-sidebar` | CSS `background-image: url('/images/sidebar-bg.jpg')` |
| `duck.jpg` | JPG (15 KB) | Enterprise confirmation modal visual illustration panel | Direct `<img>` in `Views/Shared/_ConfirmationModal.cshtml` |
| `access-denied-duck.webp` / `.png` | WebP (16 KB) + PNG (32 KB) | Shielded mascot illustration on `/Account/AccessDenied` | `<picture><source srcset="...webp"><img src="...png"></picture>` |

> [!IMPORTANT]
> **Asset Preservation Rule:** Do NOT delete `.jpg` or `.png` companion files. Browsers without WebP support, image exporters, and HTML standards require valid fallback sources.

## 4. Core UI Components

### 4.1. Split-Screen Confirmation Modal (`#dssConfirmModal`)
Defined in `Views/Shared/_ConfirmationModal.cshtml` and orchestrated globally by `DSS.showConfirmModal(...)`:
- **Left Panel:** Fixed 220px visual illustration panel rendering `duck.jpg` with cover sizing.
- **Right Panel:** Title, badge icon, descriptive body message, optional consequence warning callout (`.dss-modal-consequence`), optional multiline notes input, and action button footer.
- **Accessibility:** Trap focus, ESC key handling, backdrop click closure, aria attributes (`role="dialog"`, `aria-modal="true"`).

### 4.2. Decision Matrix & Saaty Pairwise Scale
- Pairwise comparisons use explicit fractional codes (`"1/3"`, `"1/5"`, `"1/7"`, `"1/9"`) paired with numerical decimals (`0.3333m`, `0.2000m`) in `Constants/SaatyScale.cs`.
- Diagonal cells are locked to `1.0`.
- Symmetric cells automatically invert both code and reciprocal value without rounding discrepancies.

### 4.3. KPI & Status Cards
- Rendered on `/Dashboard` and `/EvaluationBatch`:
  - Blue (`--sky-dark`): Draft / Evaluating batches.
  - Green (`--sage-dark`): Approved decisions, low CR (< 0.10).
  - Amber / Red (`--terracotta`): High CR (> 0.10), Rejected decisions, Cost criteria.
